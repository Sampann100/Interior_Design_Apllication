🛋️ Interior Design Application

A full-featured Interior Design E-commerce Web Application built using the MERN stack.
It includes AI-powered chatbot support, product management, secure authentication, real-time cart operations, and a modern responsive UI.

🚀 Live Demo
🔗 Deployed Link: https://interior-design-apllication-git-main-sampann-neemas-projects.vercel.app

📌 Project Features
🛍️ User Features
Browse interior design products
Add to cart, update quantity, remove items
Checkout flow
User sign-up & login using secure HTTP-only cookies
User profile page
Order summary & details

🤖 AI Features
AI-powered chatbot for design suggestions & customer support

🛠️ Admin Features
Add / Edit / Delete products
Manage categories & inventory
View user orders
Dashboard analytics (optional)

🎨 UI / UX
Fully responsive layout
Clean modern design
Fast loading and optimized performance
